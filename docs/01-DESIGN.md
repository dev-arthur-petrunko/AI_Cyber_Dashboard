# 01 · ДИЗАЙН — CYBER SENTINEL (ч/б редизайн)

> Полный снимок дизайн-системы для анализа и редизайна. Все значения — из кода `frontend/`.
> Правило проекта: **только 3 докс-файла** (этот + `02-ARCHITECTURE.md` + `03-RUNBOOK.md`).

## 1. Концепция

**«Чернила на тёмной бумаге»** — строго монохромный интерфейс: чёрный / белый / серый.
Единственный цвет во всём UI — **красный `#E5322D`**, и только у агента в эмоции `angry`.
Исключение по запросу владельца: **флаг Украины** в национальных цветах `#005BBB / #FFD500`.

Тёмная тема — по умолчанию; светлая (`#FAFAFA` «бумага») — через переключатель, сохраняется в `localStorage.theme`.

## 2. Цветовые токены

### 2.1 Семантические (Tailwind, `tailwind.config.ts`)

Имена **не переименовывались** (на них ссылаются страницы), значения — RGB-триплеты в CSS-переменных,
поэтому работают и модификаторы прозарості (`bg-signal/10`), и темы:

| Токен | `.dark` (тема) | `:root` (светлая) | Роль |
|---|---|---|---|
| `signal` | `176 176 176` | `82 82 82` | нейтральный акцент |
| `critical` / **`danger`** (синоним) | `250 250 250` | `10 10 10` | максимум контраста |
| `warning` | `212 212 212` | `51 51 51` | высокий уровень |
| `info` / `primary` | `140 140 140` | `64 64 64` | базовый акцент |
| `ua-gold` / `ua-blue` | `226…` / `100…` | `96…` / `160…` | легаси-токены |

### 2.2 Системные (`globals.css`)

Тёмная тема: `--bg:#050505`, `--panel:rgba(255,255,255,.04)`, `--panel-raised:rgba(255,255,255,.07)`,
`--border:rgba(255,255,255,.14)`, `--border-strong:rgba(255,255,255,.32)`,
`--text-primary:#F5F5F5`, `--text-secondary:#B8B8B8`, **`--text-muted:#8A8A8A` (минимум контраста)**,
`--accent-line:rgba(255,255,255,.4)`, `--grid-line:rgba(255,255,255,.04)`.

Светлая тема: `--bg:#FAFAFA`, `--panel:#FFFFFF`, `--panel-raised:#F0F0F0`, чёрные бордеры/текст.

**`--panel-card`** (обе темы ≈0.85 непрозрачности) — фон карточек/таблиц: фоновые частицы
не проступают под цифрами (`.card`/`.glass-card` используют именно его).

### 2.3 Заголовки

`h1` = `<span>` внутри с `from-text-primary to-text-muted bg-clip-text` → **градиент белый→серый**
(в светлой — чёрный→тёмно-серый). Принцип «h1 содержит span с bg-clip-text» сохранён.

## 6. Бейджи и графики (без цвета)

- **Severity плотностью**: Critical — сплошная заливка; High — рамка 1.5px; Medium — тонкая рамка;
  Low — без рамки; Unknown — **пунктир**.
- **Exploit maturity**: In the wild — заливка, Weaponized — рамка, PoC — тонкая рамка.
- Графики (Sankey, спонсоры, вендоры, страны, phishing) — только оттенки серого;
  DDoS-дуги/пульсации белые; линия тренда белая + заливка `rgba(255,255,255,.35→0)`.
- Карта: суша тёмно-серая, цели — градиент серого по значению, активная страна — белая.
- Подсказка графика: **2 знака после запятой** (`0.92%`), ось Y `width=44` («0.25%» не режется).

## 8. Агент — живой персонаж

**Файлы**: `components/agent/Agent.tsx`, `AgentProvider.tsx`, `agentMachine.ts`, `useAgentMood.ts`,
`AgentLinkLayer.tsx`, `AgentRoamer.tsx`.

### 8.1 Внешний вид (по референсам)
Белая сфера с бликом сверху-слева (в светлой теме — тёмно-серая сфера), **чёрные капсулы-глаза**,
без рта и глазниц. Минимум капсулы ≥6px → минимальный `size=24`.

### 8.2 Эмоции (8 шт.)
`neutral, happy` (дуги `^ ^`), `angry` (наклон внутрь + **тело краснеет #E5322D + дрожь**),
`alert` (мелкие бегающие), `surprised`, `thinking` (вверх-влево), `sad`, `sleepy`.
Приоритет: `angry > alert > sad > thinking > happy > surprised > sleepy > neutral`.

### 8.3 Привязка к данным (`useAgentMood`)
`loading → thinking`, `нет данных / idle 180с → sleepy`, `ошибка backend → sad`,
`criticalRise → angry`, `ddosUp → alert`; клик по агенту = обновление.

### 8.4 Движения (реализация — ОДИН `requestAnimationFrame`)
- **Плавная пружина** (критическое затухание K=0.1, D=0.82): взгляд двигается плавно, без рывков.
- **Рандомные сценки** каждые 4–9 с (9 вариантов): вниз/вверх/вбок/вниз-вбок/центр,
  щурится, подмигивает (~650 мс), недоверчивый взгляд.
- **Морганное медленное**: цикл ~300 мс + плавные переходы (lerp 0.22/0.18), интервал 3.5–7.5 с,
  иногда двойное; **на hover не сцыкается** (сценки приостанавливаются, глаза открыты).
- **Hover → смеётся** (дуги) **и прыгает** (ключевые кадры присядь→полёт→приземление→отскок с easing);
  click → тот же прыжок.
- Дыхание ±2%, качание корпуса, тряска при angry.
- Реализация без CSS `@keyframes` поверх SVG-`transform` (это и было причиной «глюков»):
  все значения — `setAttribute` в одном rAF; пауза при скрытой вкладке;
  `prefers-reduced-motion` → статика (только форма глаз/цвет).

### 8.5 Ноутбук-сцена (ТЗ 4.1)
- Раз в **45–90 с** (рандомно): агент раскрывает ноутбук (scaleY от точки, 350 мс, пружина),
  **без рук**, ноутбук парит ±1.5px, на экране бегут строки кода + мигающий курсор.
- От «экрана» ноутбука рисуется **кривая Безье к случайному окну** (`data-agent-target`),
  линия рисуется 450 мс, по ней бегут 3 «пакета данных», окно получает пульсирующую
  рамку + плашку **«ANALYZING…»** (i18n, 5 языков).
- `AgentLinkLayer`: `fixed`, `pointer-events:none`, `z-20` (контент → слой → шапка z-30),
  координаты пересчитываются не чаще кадра, при scroll/resize; <768px линии не рисуются.
- Сцена завершается закрытием ноутбука (якорь → `null` → линия исчезает).

### 8.6 Роумер-агент (ТЗ 5.5)
`AgentRoamer`: раз в **20–40 с** «схлопывается» (250 мс) и появляется в другой карточке
(те же `data-agent-target`); иногда **выглядывает из-за края** (clip-path). На время
ноутбук-сцены прячется → **на экране максимум 2 агента** (логотип + один).

count-pulse, float, scan-line, glow-pulse, gradient-shift, scale-in, slide-up-fade, rotate-slow,

`@media (prefers-reduced-motion: reduce)` — глобально обнуляет анимации/переходы.
