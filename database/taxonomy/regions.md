# Регионы (UA / World)

Соответствует `Region` в `app/models/threat.py`.

| Регион | Код | Назначение |
|--------|-----|------------|
| Украина | `UA` | Записи, связанные с украинским сегментом (CERT-UA, RNBO, SSU, SSSCIP, UAC-*, ключевые слова) |
| Світ | `World` | Все остальные записи (глобальный контекст) |

## Правила разметки

1. `region` задаётся коллектором на основе источника и контекста.
2. UA-разметка применяется: явно по источнику (CERT-UA, RNBO, SSU, SSSCIP) или по ключевым словам в `title`/`summary`/`tags`.
3. По умолчанию — `World`.
4. В метриках `/stats` UA-записи учитываются отдельно (`ua_alerts`), но входят в общий `total_threats`.
